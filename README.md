## 🏗️ Build & Deploy

```bash
# 1. Compile all 373 static HTML pages, sitemap.xml, llms.txt, feed.xml, and ads.txt
node build.js

# 2. Deploy to Cloudflare Pages
npx wrangler pages deploy dist --project-name=utilforge --branch=main

# 3. Ping IndexNow (Bing, Yandex, IndexNow.org) for instant indexing
node scripts/ping_indexnow.js

# 4. Run daily revenue & telemetry audit
node scripts/revenue_check.js
```
